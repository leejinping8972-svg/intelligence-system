# 保健品持续增长选品方案（建议）

目标：找出商业上持续增长、功效依据清楚且具备进入空间的保健品。当前先按美国Amazon设计，其他市场单独取数和校准；此文是建议，不代表已接入自动筛选或执行收费任务。

## 1. 扩大候选来源，不只找新上架

按来源真实类目树覆盖保健品细分类目，逐级核对节点和分页，排除食品、化妆品、药品及器械等误混。来源节点、实际覆盖/缺失类目、页数和时间必须保留，不能将若干默认类目称为全部保健品。

并行保留三类候选：类目商品（当前有一定销量）、关键词/成分对应商品（从需求找商品）、新品池（观察新配方/新剂型）。先用已有商品资料和可用搜索条件缩小候选，再拉入选商品的月度历史，避免为全库反复购买全部趋势。

这里的“并行”指候选来源组成，不要求额外多代理、并发付费或新增渠道。本次仅实施历史趋势展示；更广的候选发现、评分和调度均未实施。

## 2. 两组候选，避免把低基数和历史不足混在一起

以下为试行起点，须在真实样本回测后调整，不是行业标准或已验证预测模型。

| 项目 | 持续增长组 | 新品加速组 |
| --- | --- | --- |
| 历史要求 | 至少4个连续完整月，有6—12月更好 | 少于4个完整月，单列为早期信号 |
| 销量规模 | 最近完整月500—10,000件作为初筛参考 | 先观察绝对新增件数和周度稳定性 |
| 连续性 | 最近3次完整月环比均为正，其中至少2次≥10% | 不硬套月环比，不用不足一个月推算整月 |
| 增量 | 最近完整月比3个月前≥30%，且至少增加150件 | 小基数的高百分比不给高置信度 |
| 销售额与价格 | 销量和销售额同向增长；检查是否持续降价换量 | 记录优惠和促销后是否留住销量 |
| 口碑 | 星级≥4.2、累计评论≥100可作试行参考，再看近期评价 | 少评论不直接淘汰，标口碑证据不足 |

所有月环比只使用完整且相邻的同来源、同市场、同聚合范围月份，缺月不补零。前三个月基数为0、断货后恢复、大幅降价、变体合并、节庆旺季及单次内容爆发单独标记，不直接当作稳定增长。真实成交价、促销、库存、变体范围不可得时，标“尚未排除”，不声称已剔除这些影响。

每月必须检视季节性；有足够历史时比较去年同月/相近季节。有条件时用同细分类目的增长作参照，区分“整个类目在涨”和“这款取得份额”。没有可比类目历史时不编造相对增速。

## 3. 商业表现和功效证据分别判断

商业判断关注销量/销售额连续性、绝对增量、价格稳定性、近期差评变化、竞争与可实现的利润。毛利只有拿到真实供货价、物流、平台费及广告假设后才计算；竞品真实广告利润、退货率、复购率通常不能从这些公开趋势证明。评论中的“再次购买”只是复购线索，不等于复购率。

功效判断按“具体成分及形态→每日实际剂量→目标人群→使用时长→研究终点”对照证据：优先独立重复的人体随机对照研究和系统综述；动物/体外研究只作机制线索。成分证据不能直接等同于该品牌复方成品证据；同时记录研究样本量、对照、利益关系、结果一致性和不良事件。标签不公布有效成分含量或配方形态不清楚，标无法匹配。

用户反馈独立保存使用时长、是否购买验证、具体改善/无效/不良反应、是否同时改变饮食/运动/用药；不同人群和使用目的分开，不把营销口号和主观好评当临床验证。公开评论可能有选择偏差，采集不完整时报告覆盖范围及缺口。

质量检测单独核实批次报告/机构名录和检测范围，用于成分含量、纯度与污染等判断；质量标识不保证临床功效或所有人安全。依据：[NIH ODS消费者说明](https://ods.od.nih.gov/factsheets/WYNTK-Consumer/)、[NIH保健品研究与有效性说明](https://ods.od.nih.gov/factsheets/DietarySupplements-Consumer/)。

“GLP-1支持”“天然替代”等名称只能作市场关键词，不能直接当作与处方药有相同效果的证据；需要落到实际配方与对应研究。

## 4. 决策呈现与运行节奏

用两个判断和一个数据置信度呈现，不用一个总分掩盖证据空白：

| 商业信号 | 功效证据 | 建议 |
| --- | --- | --- |
| 持续增长、价格稳定、有进入空间 | 与实际剂量/形态/人群相符 | 优先尽调、供货与小规模验证 |
| 持续增长 | 弱或不明 | 市场热点观察，先补证据 |
| 增长不足 | 较充分 | 检查定位、剂型或渠道差异机会 |
| 两项均不足 | 弱或不明 | 暂缓投入 |

增长结论标注高/中/低数据置信度，附原始月份、覆盖、来源更新时间和异常解释；“高置信度”也不等于预测一定成功。功效用“较充分/有限/不足/无法匹配”，避免宣称对某商品有效率。

建议每周刷新候选名单及重点商品月度历史；完整月结束后重新计算稳定增长，重点新品可利用已有每日监控看短期变化。评论与成分讨论按所需时效增量采集/周度分析；高频只在来源限制或短期变化确有价值时使用。实际请求量与来源计费要在确定候选数量后估算。

先试运行30—50款候选，人工复核10款，记录误入/漏选及促销、季节性影响，再调整阈值。输出每款“为什么进入名单、增长证据、功效证据、当前未知、下一步”，再决定是否扩大覆盖或自动化。
