## 问题与行为

2026-11-11 有界公开访问复现：正式服务器访问 Ambrosia、Just Ingredients 的部分商品 HTML 返回 HTTP 429，但公开 JSON 商品目录、sitemap 仍可返回 200。原监控在读取目录后继续遍历栏目、详情、变体与多语言目录，因此即使已读到商品，也可能长期无法建立完整基线。BulkSupplements 的公开 sitemap 索引有 4,117 个入口，其中 1,029 个为不同语言路径下的商品 sitemap。

- 已识别的 Shopify 站点优先按每页 50 件读取公开 `products.json`，保留独立分页游标、商品计数与页面指纹。短页仍继续读取，直到得到有效的空结束页。仅在此前已有可验证商品、分页连续且未重复时，才以该完整公开目录结束本轮监控；不再要求额外遍历全部 HTML 页面。这里的完整范围是该站公开目录，不代表未公开商品或所有地区店铺。
- 新策略接续旧检查点时重新从目录第一页枚举，保留原观察记录、基线、冷却及请求账本。只有完整目录确认结束后才替换旧备用链接图并清除旧截断标记；目录仍分页、初页为空、格式错误、重复页、跨站跳转或请求未确认时均不能据此清除缺口或建立基线。显式待处理的浏览器步骤仍遵守原浏览器开关和次数保护。
- Shopify 栏目下的商品链接与带 variant 的链接归并为同一商品 URL；其他平台保留 variant。归一化 www 入口时同步处理旧 visited 和浏览器方法映射，不放宽跨站地址限制。
- sitemap 索引存在明确商品子图时使用商品子图；只有文件名和 from/to 范围均与当前目录的主版本相同，才排除语言副本。不同商品范围、明确语言目录与无法识别类型的索引保留。真实 BulkSupplements 索引经该选择只剩 1 个主商品 sitemap。

没有公开目录或目录仍限流时继续原备用来源、Retry-After、20 秒页间间隔、每日 3 轮恢复和浏览器限制。没有增加收费渠道、来源请求重放入口或历史业务回填；未修改来源字段整理和新品入池规则。两条公开路径都被目标拒绝的站点仍需要单站适配或另行评估数据渠道，不能据本次验证宣称所有监控恢复。
