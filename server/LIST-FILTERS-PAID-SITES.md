# 列表筛选、商品上架时间与 Semrush 独立站发现

## 交付范围

- 四核心列表默认原有列；列预设和适用的统计周期可直接点击。关键词研究移除顶部两段说明，四列表筛选随可用宽度换行，检索覆盖中英文关键词及现有商品、站点关联。
- 商品原有列及卡片增加累计展示已售和来源上架日期。自定义区间含首尾日期；近7/30/90天按北京时间日历计算，包含当天。指定日期时排除没有可核验上架依据的商品，筛选、全选与导出共用后台条件。
- 站点库和已入选关键词增加 Semrush 独立站采集入口。可填写多个关键词，设置市场、每页条数、每词页数、去重站点数及 API units 上限；沿用后台任务查看和取消。

## 数据边界

- 累计已售保留平台精度与原文，不换算为周期销量；平台缺失时显示未知。
- 上架日期复用 `decisionData.listing` 的来源、市场、平台、采集时间及公开证据校验。官网采集保留 Shopify `published_at` 和结构化商品 `releaseDate`/`datePublished`；不把建档、首次发现、系统采集时间当作上架时间。已有商品不会仅因升级代码而自动获得日期，需要来源原已提供或后续正常补全。
- 新操作只请求 Semrush `phrase_adwords`，不发起 Brave、ScrapeCreators 或官网访问。报告给出付费搜索广告主线索，不能据此证明独立电商类型、实际访问量或销量；新站标记电商待核验。已有站点的品牌、类型、收藏及指标保留，只合并新来源证据和关联。
- 按现有报告口径每行预留20 units，按实际响应记账；预算不足缩减最后一页，扣费未知即停止。每页固定 journal 步骤，已完成请求恢复时复用，未知请求不自动重放。实际价格及权限仍受服务商约束。

## 集成注意

- 基线 `825d264adac98adea2f09d19da7bed0ebb800a17`，分支 `codex/list-filters-paid-sites-20261022`。本功能会话不修改 testing、不部署正式。
- 无业务表迁移。派生读取模型升级为 `workspace-reads-v4-listing-search`，需要现有索引重建流程完成后验收上架日期筛选。集成发布应沿用索引锁、预热、完整性核对与回退，不能跳过尚未重建的商品。
- `server/model.js` 对应更新后的核心指标打包；`server/collector.js` 与 worker 的三处来源日期字段同步。
- 与商品资源获取任务共用 `products.vue`，与其他任务共用 `index.mjs`、`runner.mjs`、`store.mjs`、`market-jobs.mjs`、`workspace-reads.mjs`、`product-queue.mjs` 及 CI。通过 Git 合并，保留其余来源、周期口径、任务与分页逻辑。
