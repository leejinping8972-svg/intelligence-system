# 业务资源统一市场切换

基线：`05ba05ccc42cdaa3e2fbaa19121c2801277dd7f2`。分支：`codex/resource-market-switch-20261020`。功能开发交付，未合入 testing、未部署。

## 行为

- 共用 PageHeader 的可选 Boolean 参数被 Vue 默认转换成 false，原来的默认入口因此隐藏。现在明确设置 `showMarket: true`，在标题旁固定显示“浏览市场”。账号管理、代码提交日志显式隐藏市场控件。
- 沿用现有 ALL / US / MX / VN，不增加来源不支持的国家。所有使用共用页头的资源页面使用同一个 `state.market`，跨页与浏览器缓存沿用选择。资源数量、导出和已有统计继续使用对应市场的数据。
- 用户手动切换时，先移除当前路由中上一市场的关键词/站点/报告上下文，再切换市场，防止旧链接重新强制切回。保留无关的视图参数与 hash；直接打开关联链接仍可定位原市场。
- 关键词清空勾选、详情和市场相关标签；独立站清空勾选、详情与旧动态筛选并回第一页；商品清空对比/详情和旧来源、站点、关键词等动态筛选，沿用现有分页重置。广告清空采集选择、详情、旧报告结果，按新市场重新读取报告。
- 已入选关键词、趋势、机会研究、审核、监控沿用已有市场过滤；补充趋势选词同步和雷达详情关闭。公共情报源/雷达去掉重复的市场下拉框。
- 公共内容按研究市场上下文过滤任务、条目、收藏和类别数量，切换后清理详情、分页及旧关联选择。研究市场不等于作者所在国，全球参考证据保留原始范围与地域说明，不改写为本地作者数据。
