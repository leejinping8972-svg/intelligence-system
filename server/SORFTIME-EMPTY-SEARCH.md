# Sorftime 商品名称搜索空结果

Sorftime `product_search_from_name` 在没有数据时可能返回 MCP 文本块
`No data available.`，而不是 JSON。旧适配器对该成功空结果执行 JSON
解析，错误记录“平台返回格式无法识别”，导致商品发现任务显示
“已停止 · 未采集完”。

商品发现适配器仅对搜索操作识别这一精确文本：非 `isError`、没有
`structuredContent`，且只有一个 `text` 块。结果保存为空商品列表、
`sourceRows=0`、`hasMore=false`、`providerCalls=1`，并保留原始
`sourceMessage`；执行记录说明来源无数据、搜索已完成。

其他来源继续执行，三路均为空且无错误时任务正常完成，入库数量为 0。
不放宽商品标题匹配，不生成商品或指标，不发起额外翻页、重试或 AI 调用。
错误标记、错误 JSON、混合文本和无法识别的响应仍失败；结构化数据优先，
详情等其他操作仍按原解析规则处理。

历史已停止任务及失败账本保持原状，本改动不包含正式数据修复或重跑。
“无数据”只代表本次市场和查询条件下来源没有返回商品，不证明该品牌
或商品不存在。来源调用是否扣费仍遵循来源账单，不把空结果记为免费调用。

验证：`node --test server/sorftime-empty-search.test.mjs`。专项使用合成
工具/队列，覆盖精确空结果、真实错误不被吞掉、结构化商品优先、详情保护、
三来源空结果正常完成，且不写业务商品、不调用 AI、不重试。
