# 重点监控统一展示与广告主批量监控

基线：本机 testing `7398332d854e66f3d19f05ad5f880b8a378c4624`。独立功能分支，不修改共享testing、不直接发布正式。

## 页面行为

- “监控与任务 → 重点监控”同时显示原商品监控、`competitor:target:*`独立站和广告主监控。暂停对象也显示，数量跟随市场；提供类型/启停/名称或Page ID筛选和分页。
- 展示类型、对象、市场、每日时间/预算、监控内容、真实最近执行状态/请求/上新数量/错误。未执行不伪造完成状态，原商品行保留原频率/启停配置，并标明“商品监控配置”。商品的实际后台价格/库存采集不在本次扩展范围内。
- 独立站/广告主支持管理员直接启停、修改每日小时/预算、移除配置（保留历史与采集结果）及查看资源。即使原站点/广告素材已删除，仍能看到并管理已保存的监控。启停不重设预算、不重放本日请求，沿用原调度去重和锁。
- 广告观察新增“广告素材 / 广告主”页签。广告主按市场+精确Meta Page ID汇总，显示名称、Page ID、已存广告数量/投放中/已停止、同市场关联站点和最近真实采集时间。数据仅说明当前已保存/筛选广告的覆盖范围，不冒称广告主全量投放或真实销量。缺Page ID素材保留原列表，不按品牌名猜身份。
- 广告主列表支持搜索、跨全部筛选分页全选、清空选择、分页及批量加入监控。预览新建/已有/剩余名额与请求预算；总容量沿用100个站点和广告主对象，超额整批拒绝，不截断名单。新对象默认暂停，管理员可显式启用，新增对象只检查该广告主新广告；已有监控的启停、时间、预算、关联站点保持不变。
- 同一市场同Page ID多条素材只保存一个监控；同名不同Page ID、同Page ID不同市场分别处理。保存后刷新共享监控状态，切回“重点监控”可见新增对象。市场切换清理旧Page ID路由上下文。

## 服务端与同步

- `server_competitor_overview`只返回targets/runs，避免轮询热词排名/事件和其他大字段；沿用登录权限，研究员可读。
- `server_competitor_advertiser_batch_save`管理员专用，从已存广告读取市场/Page ID，不信任客户端品牌身份；验证全部记录、现有监控和剩余名额后事务写入，失败整批回滚。
- `server_competitor_update`管理员专用，只改计划字段，保留身份/关联/首次创建等元数据。仅启停时保留最新服务器时间/预算，暂停清除待手动执行标记。
- 所有写操作复用既有`competitor-runner`锁，无新worker、数据库表或依赖。没有自动启用既有监控或触发收费查询。
- 前端共享工作区在页面激活时刷新、使用时15秒轮询、离开后停止；合并并发读、读失败保留已有列表。变更后等待在途旧读完成再重新查询，避免旧快照覆盖新设置。
