# 商品趋势指标能力声明

Sorftime `product_trend` 的指标参数可能是普通 string：支持值写在 description 的 `Metric=meaning` 列表，而不提供结构化 enum。仅检查 enum 会误拒绝已经支持的 DailySalesVolume，也会误拒绝 SalesVolume/SalesAmount。

适配器优先使用显式 enum。没有 enum 时，仅接受 string 参数 description 中独立列出的、带赋义分隔符的当前已适配指标。缺少声明或只出现相似名称时仍不调用；显式 enum 排除的值不会被说明文字重新放行。请求始终明确指定指标，不依赖默认月销量。

返回值继续区分日/月粒度，校验商品标识、指标和必填参数；历史缺失值保持 null，真实 0 保持 0。日销量直接取来源返回，不使用月销量快照相减。

图表合并已保存的历史观察。某日新采集失败不清空旧历史，因此旧图表仍有值并不表示当天已刷新成功。此兼容修复不会删除或重放已保存的 unsupported 响应，不自动补跑旧任务、不修改监控配置；部署与历史恢复需分别记录。

任务候选 pending 表示本轮判定尚待确认，与业务商品是否已在以前轮次入库分别存储。翻译异常、分类/用法引用未通过、上架或销量证据冲突均可能使候选待确认；已入库商品不会因为新一轮候选待确认而自动删除。不能将待确认数量当作尚未入库的商品数量。

`product-watch-capability.test.mjs` 以合成商品覆盖说明文字能力、显式 enum 优先、日/月区分、缺失与相似声明拒绝、明确指标请求、必填参数变化及来源身份拒绝；不发起真实来源/模型请求。
