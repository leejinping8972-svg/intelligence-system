# 采集与中文翻译异常隔离

关键词保存、公共采集响应、商品/广告入库以及字段分析后的翻译使用 `translateCollectionRecords` 的 `context.optional=true` 模式。平台商品及发现监控的默认商品翻译器也使用该模式，避免入库前的第二次翻译再次阻断采集。严格翻译模式保持原有校验：普通关键词译文必须包含中文，原文不冒充中文译文；仅明确的品牌字段允许原样保留。没有可靠中文名称的品牌词、专名也能按原词入库并继续采集。专门请求翻译的关键词中文名接口仍使用严格模式。

可选模式将中文翻译缺失记在记录的 `collectionTranslation.status=partial` 和 `message`，保留原始字段、人工中文名称和已经取得的有效译文，其他批次继续处理。缺失配置、网络错误、格式/中文校验失败和结果未知均不会把已成功采集的响应变成来源失败。采集来源本身的错误和数据库入库错误仍按原流程处理，取消仍然有效。

翻译请求仍然先登记、再调用模型，并先保存原始响应后校验。已有 invalid 或未知 started 请求不会自动重放，不删除旧缓存、不补造汉字、不增加重试。不同文本可继续正常翻译；一次部分失败的批次会从缓存取回有效成员。翻译结果未知仅隔离对应翻译，不阻断其他来源采集。

任务详情在采集完成后显示中文翻译缺失警告；partial/failed 关键词发现任务会同时展示真实停止错误和进度汇总，旧记录中的翻译校验异常也能展示。已停止且未执行的月搜索量显示“未执行”，不再显示“等待执行”。

所有已停止任务的列表、分页、快照和详情都会从现有检查点、失败/未知请求账本、关联分析子任务补取原因，不执行业务回填。已有具体原因优先于统计汇总和未知扣费提示；执行记录保留具体错误及限流/权限分类。确实没有证据的历史任务明确显示“历史记录未保存具体错误”，不推断为余额或来源故障。分析失败按原因分组显示数量，超过三组提示查看详情；已取消分析单列，原始采集已完成时显示“采集完成 · 分析未完成”，不再误报未采集完。

Sorftime 异常预览按对象中的字符串逐项脱敏后留存，隐藏令牌及私人 MCP 地址，避免错误处理丢失已有预览。模型 JSON 解析和字段校验错误留存有限长度的返回预览。历史错误中原本没有保存的来源响应无法恢复，也不会为诊断重复发起请求。

专项测试覆盖原样返回 elahring、批次部分失败、旧无效/未知记录、跨批次、关联查询、取消、保留人工译名及隔离数据库中的真实关键词保存和任务恢复。另覆盖实际商品/广告入库、广告字段成功但翻译无效时的保存及父任务计数、历史失败原因聚合、响应预览脱敏和无效模型 JSON。测试中的来源和模型均为合成响应，不调用正式收费接口。

这是功能开发修复，不改变正式任务状态，不自动恢复历史任务，也不执行业务回填。正式上线后再由用户选择继续原任务，按原检查点和请求账本处理。
