# 资源采集时间与关键词中文名称

分支 `codex/resource-time-names-20261020`，基于已确认 testing `07b3bc8a14200db24c53dd5fbd8dcafea2bd450a`（含紧凑资源 `41eb01d`）。用户授权交付后由发布会话 `01a153ca-9593-7360-aa4c-6db54fbe5487` 合并、CI和正式发布；功能会话不自行部署。

## 行为

- 独立站/商品列表增加可排序的采集时间列，卡片及详情也显示。统一北京时间。读取成功采集记录 `lastCollectedAt`，站点来源采集证据 `sourceEvidence[].collectedAt`，商品平台/内容采集记录；使用其中最新有效时间。来源发布日期、首次发现时间、任务开始/结束和SEO指标抓取不替代资源采集。没有数据显示“未记录”，仅日期的历史字段明确“仅日期”，不补造时间，也不重采历史数据。
- 商品库首次进入默认列表，仍可切换卡片。导出增加采集时间原值。
- 关键词研究和已入选词保留原词，新增中文/中文参考译名，支持中文搜索；研究详情/导出也显示。保存的 `termZh` 优先；未保存时本地营养词表提供阅读参考（未知品牌/专有词保留原文，无法识别显示待补充）。不是全语种完整机器翻译，不冒称人工校对结果。
- 选择1～50词后“中文名称”打开校对表，可手工修改并保存。管理员可手动点击“使用已配置模型翻译（按模型计费）”，只用已有语义模型发一次请求；不自动请求或重试，不发送Semrush/广告采集请求。译名数量/ID/长度/中文内容校验，不完整时保留原数据。模型用量返回后显示，需校对保存；少量输出预算可通过减少词数解决。

## 数据与接口

新增可选 `Keyword.termZh`，原 `server_patch_keywords` 保存，云端editable同步支持。`cleanKeyword`限制为255字符；`saveKeyword`普通补采和重复导入保留原中文名，保留原ID、人工入选/收藏/备注及关联。无数据库结构迁移、依赖或锁文件变化。

新增 `server_keyword_names` 只返回译名草稿，不自动写业务库。管理员鉴权，1～50不同ID，从数据库按ID读取原词，不能由客户端冒充原文；请求已存配置模型，费用由用户明确点击触发。无额外队列/调度/发布排空锁。复用model-provider现有公网HTTPS限制、输出上限、90秒超时与模型错误处理。模型未配置可手动填写。

共享入口按diff合并：sites/products/research/selected-keywords、ProductDrawer/SiteDrawer、data.ts单字段、cloud-workspace单editable字段；server/domain清洗与patch字段、store两个数据库upsert保留字段、index仅挂动作；testing.yml追加测试；原竞品隔离集成追加中文名持久化回归。保留其他会话功能，不整文件覆盖。

## 验证和边界

- 26项前端相关回归（含真实采集时间选择/北京时区/缺失与日期、中文参考和专有词、选择与同步/市场）；8项Node相关回归（中文字段、模型响应校验、权限/限额/一次调用、无自动重试及原domain）。
- 隔离PGlite实际事务集成通过，新增普通重采/重复导入后中文名与ID不变验证；同脚本在已有CI隔离MySQL步骤执行。本机未执行MySQL/远端CI。
- web-antd类型检查、服务器/history构建；新模块Oxlint/ESLint、diff与commitlint通过。旧共享文件不做全仓自动修复；沿用已记录单次临时hooksPath，不改变仓库/全局钩子配置。
- 浏览器使用本机合成数据、假模型接口，不含生产数据、Key或实际付费调用。模型真实账户权限与翻译质量未通过真实收费调用验证。

历史数据未记录的采集时间无法逆推；中文参考词表有覆盖范围，未知词需校对或手动模型翻译。发布不得自动翻译全部历史词、重放正式采集或购买额度。
