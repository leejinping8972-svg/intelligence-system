# 西之月上架时间与展示销量

- 目录卡片上架日期来自 `product_addtime`，保留原始时间及目录证据；不以系统发现时间替代。
- 目录卡片销量展示为 `month_sale + "+"`。详情接口 `month_sale` 已返回带加号的字符串时直接保留，不重复添加。
- 保存 `soldRaw`、`soldPrecision=lower_bound`、`soldPeriod=unspecified` 及来源字段、网址和采集时间。不给它赋精确销量或月销量。
- 首次目录采集与每日监控复用同一解析；每日更新这两项时保留人工状态和其他补全结果。
- “补全商品数据”按原链接中的商品编号读取官网公开 GET `/product-center/shop/products/detail?product_id=…&locale=zh_cn`，最多一次请求，核对返回编号后保存；已有目录上架原文优先使用其原采集时间。
- `westmonth-metrics-backfill.mjs` 只生成越南西之月已有商品的缺失项回填计划，批量目录与精确详情均有请求上限。它不自行连接数据库或执行写入，不在启动时运行。运维写入须保留定向恢复副本并走既有商品保存/证据/投影流程。

验证包含目录首抓、每日合并、详情补全、原始加号、未知口径、编号不匹配、429保护、已有字段保留，以及真实隔离 SQL 的提交、请求计数、分页展示和导出。
