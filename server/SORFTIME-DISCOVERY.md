# Sorftime新品与成分研究（2026-11-05）

用户最新要求覆盖此前官方榜单默认方案：所有新提交的新品、成分研究均使用服务器现有Sorftime MCP；官方网页模块仅保留显式兼容路径。没有schema、业务迁移、依赖或启动写入变化。

## 新品

- Amazon/TikTok/Shopee先用Sorftime类目查询获取真实类目ID，再按类目分页检索；不把固定词组传入商品标题/属性搜索。只入库AI确认是口服保健品的商品。类目查询最多接纳100个去重ID，不再任意只取前三个或用英文名称排除越南类目。
- Amazon、Shopee使用`online_date_range_min/max`；月销量最低1分别使用`month_sale_volume_range_min`。TikTok用`exposure_time_min/max`查候选、`month_sale_count_min=1`，曝光时间不当作首次上架日期；若未另返回明确上架日期，则跳过并记录证据不足。
- 本地再次核对日期在北京时间所选窗口内、来源报告月销量>0。适配实查返回的`monthly_sales_volume`；Amazon月销量为Sorftime估计，不声称所选滚动30天真实订单。
- FBM限Amazon，传`shipping_type=FBM`；来源行有明确发货方式优先使用，缺失时保存工具实际查询条件作为发货筛选证据，标明`source_query_filter`。
- 商品上限1000，每类目最多100页、每页来源最多20。上限不保证抓满；页数、重复页面、来源覆盖均限制结果。30天FBM仍归属FBM分类。

## 成分

- Reddit/Quora搜索和原文/评论通过Sorftime，按真实`published_time`本地过滤，兼容完整帖子PascalCase。US为研究归档市场，不表示来源已按美国用户过滤。
- Reddit搜索返回摘要时，仅将有效`t3_`来源ID映射到标准帖子链接，符合日期才请求`reddit_post_request`取得原文；摘要不作为原文引用。原文ID不匹配拒绝。Quora原始标题可以作为原文，来源摘要不混入正文。
- 上限5000条讨论，原文补取计入同一容量，评论/回答仍受maxDetails控制。AI按最多40条/40000字符分批分析，检查点恢复和请求账本防重放沿用原机制。
- 持久保存来源条数、缺日期、超出日期、缺链接、缺原文、错误主机等计数。空数据的已知MCP文本`No data available.`/`No relevant data.`作为正常空结果；isError和未知文本仍报错，不自动重试。

## 实查与验证

实际生产MCP目录118个工具。只读探针已验证Amazon真实返回近30天上架及月销量>0的商品；TikTok美国与Shopee越南单类目样本返回空。Reddit旧适配确实漏读`published_time`，搜索返回空URL且仅摘要；完整帖子字段存在大小写差异。探针收据保存在忽略的发布目录与服务器临时目录，每个探针调用前落盘，未知结果不重试。真实响应和凭据不提交Git。

功能专项覆盖类别/日期/销量参数、空文本、日期边界、摘要补原文、ID核验、5000分批、SQL幂等与任务提交。正式发布按当前用户策略保留部署/队列/数据保护，跳过发布阶段重复验证与CI等待。
