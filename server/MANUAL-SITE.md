# 手动添加独立站

## 入口

竞品独立站 → 手动添加独立站。填写公开网址、归档市场及可选品牌名，可同时提交探索或深度商品采集。网址可省略 https://；市场不根据域名推断。

`server_manual_site_add`先通过已有DNS固定的公开页面读取器核对网址，再提取品牌、页面描述、平台、结构化商品名称和电商证据。数据不经过付费模型或托管服务；流量与股权未知时保持待核验。资料读取失败不会创建站点。

相同市场与标准化域名复用已有ID，保留人工品牌、收藏、关键词及历史关联；站点与商品任务、请求回执在同一事务中提交，队列满则整体回滚。重试同一提交编号复用结果，已有进行中的商品任务直接复用。商品使用既有`products`队列，探索30件/10件详情/20请求，深度100件/100件详情/120请求，托管备用固定0。不开启Semrush或广告采集。

## 西之月

站点为 `https://www.westmonth.com/`，属于跨境选品平台，归档市场不代表公司或商品所在地。本次用户指定归到越南。

官网页面脚本公开使用`api-x.westmonth.com/product-center/shop/products/load-list` GET目录，无需账号、Cookie或Token。新增独立`westmonth-catalog.mjs`，商品采集读全部商品目录（仍受商品/请求上限）；每日上新监控读官方公开新品榜，每页60条、跨日继续，完整扫描后才建立基线。覆盖范围是官网当前公开新品榜，不代表4万余条全站记录每天重采。后续新增观察事件是首次发现信号，不等同实际发布日期。

保留商品标题、图片、公开商品地址、SKU、目录证据URL及原始`product_addtime`。未公开价格、定义不明的销量、目录添加时间不能冒充真实价格、近30日销量或上市日期。页面/API异常或分页缺失不建立完整基线。

## 验证与发布

`node --test server/manual-site.test.mjs server/westmonth-catalog.test.mjs server/product-queue.test.mjs server/competitor-monitor.test.mjs`覆盖隔离事务、去重、重复提交、人工字段保留、队列回滚、目录分页、错误响应和旧采集回归。实际官网免费目录首屏读取另行记录，不将其当作完整监控验收。

无新数据库结构、迁移、依赖或付费任务。功能提交交付待集成后，由独立发布流程上线；上新适配代码尚未发布时不得宣称西之月每日采集已正常运行。
