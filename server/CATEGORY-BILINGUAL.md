# 商品库与产品概念的品类双语显示

商品库列表已有的 `ProductText` 组件用于机会研究的产品概念标题及详情标题：优先显示已保存的中文译名，下一行显示原文。原文使用浅色，字号比当前标题小 2px；没有译名时只显示原文，译名与原文相同时不重复显示。

`opportunityRows` 在产品概念统计行中补充可选的 `titleZh`，取同组商品中第一个非空的 `categoryZh`。原始 `category` 仍用于分组、标题标识、排序和收藏，记录数量不变，不因译名相同合并不同原文品类。缺失原始品类的记录仍归入“待补充”。其他五类页签保持原有统计内容。

研究摘要导出也使用中文主名并保留不同的原文。没有新增翻译、来源或模型请求，没有回填商品数据。

统计快照版本由 4 升为 5，并检查持久化版本。下次后台统计检查会替换旧版本的派生快照，使同一天已生成的快照也能补入中文名；完成后继续沿用每日北京时间 09:00 的刷新策略。后台刷新完成前旧快照仍可读取。没有数据库结构变更或业务迁移。
