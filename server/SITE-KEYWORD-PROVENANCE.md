# 独立站检索词与来源说明

- 实际检索词沿用原词，不按 `/` 拆分。官网商品名、页面标题、流量指标和搜索广告竞品拓展说明保留为证据或发现来源。
- 正式检索来源与官网商品名相同时，保留真实检索关联。无法证明是来源说明的历史词及人工/直接检索关联不自动解除。
- 独立站列表新增“发现来源”和“采集证据”，详情区分检索词、发现来源和原始采集记录。站点关键词选项只提供当前市场实际关联到现存站点的词。
- 筛选下拉框、清除按钮与地址中的 keywordId 使用同一状态；清除只移除关键词条件，保留其余地址参数，筛选改变回到第一页并清空行选择。
- 商品页移除截图中的“全部新旧标签”下拉框及对应请求/本地筛选状态。

## 首次启动的数据影响与回退

`store.mjs` 在既有 `workspace-reads` 锁和同一事务内执行一次纠正，marker 为 `read:site-keyword-provenance-v1`。仅处理来源为“历史业务关联补齐”、同市场且站点原始证据明确属于非检索说明的关键词双向站点关联；保留关键词记录、其他站点/商品关系和原始证据。重复执行幂等。既有 v1 回填 marker 保留，不重跑已完成的全量历史回填；站点与关键词读模型重新投影以展示来源。

本变更无表结构迁移，但包含启动数据写入。集成发布前应备份受影响的 `business:sites:*` 文档、相关 `research_keywords` 记录以及上述 marker 原值。在停止业务写入、持有发布锁和队列保护时恢复该范围快照及旧源码，再重建派生读模型；仅回退源码不能恢复已解除的关系。此说明不授权正式部署或正式数据操作。
