# 独立站/广告主上新监控与 Semrush 热词榜

基线 testing `05ba05ccc42cdaa3e2fbaa19121c2801277dd7f2`。本功能开发分支不启用正式采集，不部署正式环境。

## 功能与入口

- 竞品独立站列表/操作入口、广告观察及广告详情可加入上新监控。站点可关联广告主 Page ID，广告主可关联同市场的已有站点，以同时检查商品和广告。广告主以 Meta Page ID 精确匹配，不以品牌名称模糊搜索代替。
- 北京时间每日指定小时后执行，每对象每天最多尝试一次；可暂停、移除、本日立即检查。立即检查也遵守当日去重。管理员配置每日页请求预算；两个渠道同时启用时，官网先使用约一半预算，广告使用剩余额度。单个接口请求内部的公开 HTTP 重定向不单独计入逻辑页请求数。
- 首次完整扫描建立观察基线，首批历史商品/广告正常入库但不标上新。以后未观察过的记录产生“竞品上新”事件。首次发现不等于实际发布日期；没有证明的发布日期不编造。
- 目录通过官网结构化产品、Shopify 公开目录及站点产品链接发现。限流、异常、预算用尽保留部分结果；待扫链接/广告分页游标跨日继续，完成后下一轮从入口重新扫描。官网页请求间隔20秒。跨域产品地址不入库；可选目录404/410跳过并使用其他入口；目录上限5000待扫链接/10000已访问地址，超过则明确部分覆盖。大目录不能保证每天全量覆盖。
- 新品/新广告按实际标题、文案、已公开成分做规则提词；包含原文中的常见营养成分和合适长度的产品标题候选，不调用付费模型，不推断未公开配方。无法提词时保存事件和原因，等待人工研究。
- 候选词按市场+规范化词去重，保留原关键词ID、收藏、入选、评分指标与既有商品/站点关联。研究页的分析标签和标签筛选显示“竞品上新”“Semrush热词”。来源标签在后续正常研究重写时保留。

## Semrush 榜单口径（用户已确认）

关键词研究的“Semrush 热词榜”打开独立右侧榜单。每市场可设置1～10个保健品种子词，使用官方 MCP `get_report_schema` 与 `execute_report` / `phrase_fullsearch`，每种子按搜索量降序取100行，合并去重、按月搜索量排序取前100。少于100显示实际数量；缺失搜索量不编造为0。

这是种子覆盖范围内的本系统汇总榜单；不是 Semrush 全行业官方每日热搜榜，也不是日搜索量增长榜。保留种子、市场、报告、采集时间和原指标；每日采集不代表 Semrush 月搜索量统计期每日更新。榜单显示相较上次采集的升降/新入榜，更新后自动增量进入关键词研究，保留人工状态。未获取有效数据时保留旧榜单及其原采集时间，最新任务单独显示空结果/失败。

官方依据：[关键词报告](https://developer.semrush.com/api/v3/seo/keyword-reports/)，Broad Match `phrase_fullsearch` 20 API units/行，支持搜索量降序。每个报告执行前预留100×20=2000 units，每日上限种子数×2000；显示确认用量/未知用量状态，失败或用量未返回后停止后续付费报告。元数据握手和报告schema检查不计入付费报告次数。真实Key权限/当前MCP枚举以运行时返回为准，不支持所选数据库/字段/排序时停止并显示原因。

## 存储与任务安全

全部新配置/状态独占 `workspace_documents` 的 `competitor:` 命名空间：target、hot-config、run、ranking、history、baseline、seen、crawl、event、request。无新表/迁移，无新依赖。

采集结果写原 `business:products:*` / `business:ads:*`，关键词写 `research_keywords`。每条结果、关键词关联、上新事件与seen标记同事务保存；游标在结果事务成功后推进。复用既有数据源加密凭证。请求调用前先持久化journal，不重放started/failed未知请求；进程中断后本日标记中断并跳过，下一日按监控规则继续。不自动重试同日收费失败、不购买额度。

调度器独立于现有关键词发现/公共内容runner。进程轮询15秒，每轮最多处理一个对象；浏览器关闭后由服务端继续。配置/手动检查/移除需要管理员，研究员可读取状态。默认没有任何启用的监控或热词配置，用户保存配置后生效。移除保留历史事件/请求/seen，重加须重新建立完整基线，并保留当日去重。

## 集成与发布注意

- 新增命名锁：MySQL `intelligence:competitor-runner`；PostgreSQL `89761033`。**集成发布的排空守护必须同时持有此锁**，否则可能在官网等待/广告或Semrush报告期间中断。数据库迁移入口已与此空闲锁联动。
- `server/index.mjs`仅挂新动作、独立runner和迁库空闲保护；`database.mjs`仅登记锁；`store.mjs`仅在普通关键词upsert时保留两类来源标签。合并保留其他会话对这些文件的入口变更，不能整文件覆盖。
- `sites.vue` / `ads.vue`只挂独立监控组件，`research.vue`只挂热词侧栏及两类来源标签。与市场切换、每日入选关键词发现会话按小范围diff合并。未修改data.ts/runner.mjs/关键词评分模块。
- CI新增23项专项Node测试及独立MySQL8集成脚本。隔离脚本仅允许显式`COMPETITOR_MONITOR_QA=disposable-only`和指定QA MySQL容器；本地另支持显式提供PGlite运行时，禁用外部fetch，不读取正式配置。
- 单测/隔离验收不代表真实数据源权限或完整线上部署已就绪。部署后管理员按实际市场、种子、关联对象和预算启用；本分支没有触发真实收费来源或写正式数据库。
