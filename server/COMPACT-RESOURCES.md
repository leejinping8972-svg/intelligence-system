## 用户可见变化

- 独立站列表来源与产品标签默认最多两行，长标签/溢出标签可用按钮展开；品牌和官网来源保持两行摘要。新档案抽屉按概要、产品、评分、来源证据、运营主体分区，保留原始证据及商品/广告/消费者入口。
- 关键词、商品、广告、入选词列表使用紧凑样式和统一选择提示；商品与广告卡片增加选择框。商品详情改为图片/基本信息并排与固定底部操作，关键词评分维度卡片排列，广告详情拆分素材与文案。广告分页支持10/20/50/100条。
- 独立站、关键词增加最低/最高评分（含边界）与已评分/未评分筛选。未知不等于0；范围错误显示提示。关键词使用当前模型算出的分数。
- 表头全选及“全选筛选结果”选取当前筛选的所有分页，不再以100条截断。演示条目不可提交；切换筛选/市场清理隐藏选择。商品导出使用已选结果（没有选择时为筛选结果）；已有对比3项、补采100项等限制保留。选择本身不产生采集请求。
- 独立站批量加入上新监控支持混合市场，提交前显示新增数、已有数、剩余容量与合计预算。已有监控（包括暂停、广告主关联、时间/预算）保持原值；新对象默认暂停。既有上限仍为100个监控对象，超额整批拒绝，不静默截断。
- Semrush 配置区增加账户 API units 余额、来源、更新时间与手动刷新。保存 Key 后自动读取；普通加载只读缓存。失败显示未知与原因，不伪装为0。

## 服务端与集成

`server_competitor_batch_save`：管理员动作，沿用 `competitor-runner` 空闲锁。批量站点预检、去重、容量校验、混合市场校验后在同一数据库连接事务写入。失败回滚，其他会话/任务配置不重写；不直接执行采集。

`server_semrush_balance`：管理员动作，解密已存 Key，仅请求固定官方 HTTPS 余额地址；返回数字/0，或未获取状态。查询后缓存于原配置 `lastBalance`；保存 Key 期间更换凭据会拒绝旧结果。浏览器不接收 Key，异常会屏蔽 Key，重定向不跟随，超时12秒。数据研究仍使用现有 MCP。

官方余额说明：<https://developer.semrush.com/api/v3/get-started/api-units-balance/>；地址为 `https://www.semrush.com/users/countapiunits.html`。这是免费的标准 API units 余额查询，不等于模型 token，也不保证反映第三方转售商或独立 MCP 订阅额度。接口无权限/响应不可识别时需去账户核对。

无需数据库迁移、依赖或锁文件变更，不新增调度进程/锁，不修改抓取节奏或现有预算。Dockerfile已复制全部server/*.mjs，无需新入口文件清单。
