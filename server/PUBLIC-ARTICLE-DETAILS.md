# 公共文章正文与图表

本功能独立于检索索引、字幕和评论，不使用付费模型或采集服务。

## 用户流程

- 新搜索默认勾选“补采文章正文与图表”，先完成各来源检索，再读取已入库文章正文。可关闭此选项。
- 已保存文章首次打开详情时自动补采一次；已有正文直接读取数据库。失败后显示原因，可手动补采，不循环请求原网站。
- 详情默认展开各章节，支持全部展开/收起，展示原语言摘要、正文、数据表、图像和图注、参考文献、采集时间及来源授权说明。
- 旧的在途搜索输入没有 `fetchDetails:true` 时不增加请求。关闭详情不会取消已提交的后台正文任务。
- 成功正文长期复用；自动搜索对失败结果缓存24小时，手动补采可以重新检查。刷新正文状态仅访问本系统数据库。

## 来源与边界

- Europe PMC 优先使用官方 `/{PMCID}/fullTextXML`。旧 MED/PMID 记录先精确查询官方元数据取得 PMCID。无开放全文时保留索引，不凭标题生成正文。
- 普通机构/网页文章提取公开 HTTPS HTML 中的段落、已有折叠内容和结构化数据。拒绝明确订阅内容和验证页面，不执行远端脚本，不解析 PDF 或下载补充附件。
- 官方 XML 中的图片路径仅接受匹配 PMCID 的 NCBI 公共 CDN；普通文章图片仅保留同域 HTTPS 地址。图片仍从原官方地址加载，可能因网络/来源权限而不可用，保留图注与原文入口。
- 安全读取只允许公网域名 HTTPS；每次重定向重新校验 DNS，并将校验过的地址固定到实际 TLS 连接，保持证书验证。禁止凭证、端口、IP字面量、内网/保留地址，最多2次重定向、25秒请求、5MB响应。不携带Cookie或站点账号。
- 保留上限：240000正文字符、100章节、700文本块、40表（每表150行/20列）、30图。超限标记部分正文；HTML只标记“公开可读正文”，不宣称完整全文。外部HTML不使用 `v-html` 渲染。

用户样例 `PMC13666917` 已通过真实免费官方 XML 验证：接口有摘要（检索索引未提供），解析27个有内容章节、4表、3图、70560正文字符（包含参考文献），未截断。官方图像地址已验证可读；真实XML和解析结果只在根 `.artifacts/`，未提交真实业务数据。

## 持久化与任务

- 新增 `content:article:<itemId>`，正文与状态独立保存，不扩大列表快照；现有工作区文档备份应包含该命名空间。不改数据库表结构。
- 索引只增 `pmcid` 与紧凑 `articleDetails` 状态，原收藏、关键词/商品关联通过原有原子更新保留。
- 动作 `server_content_article_get` / `server_content_article_submit` 只接受已存在的文章编号；提交使用UUID幂等和既有提交锁，复用在途文章步骤，受既有5项活动任务上限约束。
- 文章任务继续使用公共内容runner锁。发布仍须先排空/锁住公共内容队列；本功能开发不部署，不重放正式任务。
- 失败与取消保留原索引以及已取得的正文；服务重启时结果未确认的在途请求不自动重放，可手动补采。
- 新依赖 `cheerio@1.2.0` 位于 `server/package.json` / `server/package-lock.json`，Docker既有 `npm ci --prefix server` 流程会安装，无需改pnpm锁。
