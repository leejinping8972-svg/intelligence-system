# 关键词重跑与 Semrush 积分

- 关键词身份为市场 + NFKC 标准化、合并空白、忽略大小写的词文；不同市场独立。数据库主键已有唯一约束，无业务数据迁移。
- 首次入库与重跑统一通过事务写入并锁定同一行，沿用原 ID。收藏、人工筛选、备注、中文名称以及商品/站点关联保留；新增关联合并。
- 重跑接受较新的有效指标，部分指标只更新已返回的字段，0 是有效值。年度、日趋势与历史序列按各自采集时间更新。空结果、失败或旧检查点不清空成功数据；采集状态仍可显示本次错误。
- 从种子词重新研究会重新排队更新年度及日趋势，刷新期间保留原数据；“补齐缺项”继续复用已有成功/空结果，只处理尚未完成的趋势部分。
- 导入继续仅补缺并合并来源，不用旧浏览器导入覆盖已有实采指标。补齐名单拒绝同市场同词的不同 ID，防止同任务重复付费查询。
- Semrush 独立站、平台商品、商品资源、每日采集与热词任务不再按积分预算截断；旧参数作为兼容字段归零，存量检查点也不再受积分预算约束。已结束任务不会自动重启。
- 保留任务请求次数、分页、结果数量、取消、提供方限流和真实余额限制。记录实际及预留用量；收费结果未知时停止该来源，不自动重放可能已扣费的请求。
- 本功能自测只使用合成数据与隔离数据库，不执行真实付费请求。真实 MySQL 与正式发布状态以交付记录为准。
