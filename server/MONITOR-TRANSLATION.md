# 独立站监控翻译兜底

官网新品监控 `scanSite` 读取公开 JSON、页面、sitemap，必要时使用本机浏览器，不调用 Sorftime、Semrush 或 Firecrawl。监控列表中的“请求”包括公开官网请求次数，不等于第三方收费渠道扣次。广告监控、Semrush 热词及后续 AI 字段分析分别保留原有来源/模型用量。

监控保存观察结果和衍生关键词时使用 `translateMonitorRecords`：先复用现有译文/缓存，尝试配置的模型；模型返回英文、缺项、JSON 无效、超时、配置不可用或历史结果未知时，只把仍缺失的文本交给腾讯交互翻译公开机翻接口。机翻使用自动识别语言、简体中文目标，不传分析任务、原始档案、账号或密钥。品牌允许保留原名，不用机翻编造品牌中文名。

机翻不需要新付费密钥，不消耗采集渠道额度或 AI 模型 tokens，但依赖外部公开服务，可能限流、变更或暂不可用。每批沿用至多32项/2400字符的限制；12秒超时、不自动重试，服务错误共享5分钟冷却，单条无效译文也冷却5分钟。该调用不经过付费采集/模型请求通道。

机翻缓存为 `collection:machine-translation:v1:*`，与模型的成功、无效及 started/未知请求分开。不会覆盖、重发结果未知的模型请求，也不修改已保存的模型原始响应。有效模型译文、人工译文、原文及来源证据保留，长字段只补失败片段，相同文本共享机翻在途结果并复用持久缓存。

模型与机翻均失败时，记录 `collectionTranslation.status=partial` 和实际警告，保留原文继续保存观察结果、推进完整扫描基线。官网限流、HTTP 500、目录覆盖不完整和业务写入失败仍按原采集错误处理，未放宽新品证据或入池规则。共用观察保存路径中的广告也使用此兜底；Semrush热词和其他采集入口保持既有行为。

无 schema/迁移、依赖、队列、收费配置或前端变更。不会自动恢复或重跑历史监控；需要集成发布后才会用于正式后续执行。
