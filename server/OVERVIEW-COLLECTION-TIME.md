# 总览新品与采集时间交付

状态：功能开发完成，待独立集成；本分支未发布、未修改共享 testing、未触发正式采集或任务重放。
基线：83655108edf2ce15e8b9191e77c8ddfe230cadf6。

## 行为

- 总览增加“今日新品发现”和“独立站监控异常”，前者按北京时间首次发现日期且当前已入新品池的商品去重计数，点击打开同市场新品池与相同发现日期筛选。采用首次发现日期，不按再次采集或重复分类时间累计。后者统计已开启独立站监控最近执行的失败、受阻、部分完成、中断与等待重试，点击进入重点监控；不包含商品持续观察。页面处于活动状态时每分钟更新，停用后停止轮询。
- 商品、独立站、广告、关键词共用北京时间采集日期范围、今天及近7/30/90/180天控件。首尾日期均包含，服务端将结束日转换为次日零点的排他上界。商品上架日期控件保持独立。采集时间仅采用成功采集字段，商品取内容/指标/最近采集的最新时间，站点取来源证据/最近采集的最新时间，不用首次发现或上架日期替代；缺日期时不命中有日期条件的检索。
- 筛选在服务端分页、全选、导出名单生成前执行，改变筛选会清空选择、重置分页；关键词保存视图携带自定义日期并兼容旧视图。旧滚动时间预设和自定义日期互斥。商品总览深链接清除其他列表筛选，提供清除发现日期操作。
- 独立站监控清除旧待抓队列及新发现链接中的样式、脚本、图片、字体、订阅和oEmbed资源，继续保留公开商品页、Shopify JSON目录与sitemap。不会清除业务数据、重置基线/截断标记，或放宽跨站限制、请求账本、冷却和重试限制。
- 独立站新发现和基线补抓商品在正常持久化时，若本次来源提供可靠上架日期（执行日前7个完整自然日）与同次采集的正销量证据，自动写入“新上架商品”入池证据。缺日期、曝光替代日期、旧日期、缺/零销量、过期或无来源的销量均不入池；不会额外抓取销量、执行付费报告或回填历史商品。已有入池记录保留，重复采集不反复追加入池记录。监控界面将“项上新”改为“项新发现”并解释首次发现与上架的区别。
