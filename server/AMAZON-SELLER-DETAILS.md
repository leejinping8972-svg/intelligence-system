# Amazon 卖家公开详情

商品列表、卡片及详情中的卖家名可点击查看企业名称、公开营业地址、国家/地区、来源和采集时间；取得真实 Seller ID 后显示对应 Amazon 站点的卖家主页。保留原始企业名称及地址分行，不将品牌、制造商或发货方当作销售方。

## 采集与保护

- 接入现有商品 intake，先完成商品详情/内容，再取得卖家资料；点击展示不发起来源调用。
- 已有 Seller ID 时仅查询 `seller_detail`；缺少 ID 时先以完整卖家名调用 `seller_search_from_name`，仅接受唯一精确匹配，再查询详情。最多增加两次数据调用，每步各占一条现有请求账本、一个 Sorftime 调用额度，沿用商品任务的预算、取消及未知请求保护。
- 始终显式发送来源站点，不用业务展示市场代替来源市场。返回的卖家名、ID、站点有冲突则拒绝保存；不从搜索结果选相近名称。接口未开放、资料缺失或调用失败均保留商品本身。
- 匹配的已保存详情七天内复用；卖家名、ID或来源站点改变时旧资料失效。成功匹配但企业字段为空时明确显示未取得。历史记录不自动批量补采；随正常采集/资料补充取得。
- 资料使用现有商品文档和增量列表投影保存，无 schema、迁移、启动回填、依赖或读模型版本变更。

## 验证

2026-11-10 对一个美国站真实卖家进行了有界验证，共三次现有渠道数据调用（按名详情、按 ASIN 查卖家、按完整卖家名查 ID），均取得明确响应，未重试。其中 ASIN 查询为空，不能把该路径视为可依赖的商品卖家识别方式。

免费公开商品页两次均能访问，但受配送地区影响没有显示卖家；已知真实 ID 对应的 Amazon 公开卖家页可访问。候选解析器离线重用已保存响应，企业名称和六行地址与该公开页逐项一致。只实测美国站样本，不宣称所有站点或所有卖家都有企业地址。真实响应和公开页仅保留在本机 `.artifacts/`，不提交业务资料。

相关合成测试覆盖身份冲突、缺失资料、调用用量、未知请求恢复、七天复用、卖家变更失效、列表投影、地址分行与网页安全展示、站点链接及点击不触发行操作。正式账户界面与其他国家实时来源尚未验收。
