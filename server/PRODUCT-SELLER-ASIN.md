# 商品卖家、亚马逊链接与观察节点提示

- 列表卡片、表格和商品详情按“卖家：名称 / 品牌：名称”分行展示。Amazon 来源未返回卖家时显示“未返回”，不以品牌、厂家或发货方推断卖家，不猜测卖家国家或卖家数量。
- Amazon 搜索、资源采集、新品发现、详情补取与官方详情页会保存明确的销售方为 `sellerName`。部分刷新缺少卖家时保留已知值，来源返回新卖家时更新。
- 历史资料优先复用已保存的 `resourceRaw.shopName/soldBy`、`sourceMetrics.shopName` 和资源证据商家名。旧列表摘要只按当前页商品编号批量读取这些字段；不做全量索引重建、启动回填、迁移或额外收费采集。历史来源没有保存卖家时仍缺失，需后续正常详情采集取得。
- ASIN 在新标签页打开 Amazon `/dp/ASIN`。优先来源市场，其次匹配同一 ASIN 的已知 Amazon 原链接，最后才使用商品市场；研究市场 VN、来源 US 的商品跳到美国站。无有效 ASIN 或无法确定站点时不创建链接。点击不触发行点击事件。
- 持续观察图拆出 `ProductWatchChart.vue`。节点扩大命中范围，悬停立即显示日期、指标及数值，价格指标含币种；键盘聚焦和点击也可查看，Escape 关闭。部分数据保留提示，缺失值不补零、不跨缺失日期连线。
