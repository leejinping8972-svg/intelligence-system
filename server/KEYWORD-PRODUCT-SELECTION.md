# 关键词选品研究评分

版本：`product-research-v4.1-intent`。适用口服营养补充剂概念研究阶段，帮助排序研究投入，不代表备货、人体功效或盈利判断。

## 分数与证据门槛

| 分数  | 建议                                                       |
| ----- | ---------------------------------------------------------- |
| ≥80   | 优先深入研究，核验实际商品、销量、复购、毛利与目标市场准入 |
| 65–79 | 继续观察，补充口服商品与细分需求证据                       |
| 50–64 | 低优先观察                                                 |
| <50   | 现有信号弱时暂缓；缺数据时先补证据                         |

这些是初始业务阈值，不是经成交结果回测得到的成功概率。后续需用实际研究结论与经营结果校准，不能凭本批分数高低证明阈值准确。

缺少搜索量或有效趋势，最高64分；两者均缺，最高49分。缺少可追溯的口服商品原文线索，最高79分。明确返回零搜索量最高49分。外用、注射、科研、明确否定口服等非目标用途最高19分，偏离研究成分最高39分；品牌、纯导航最高64分。多条限制同时命中取最低上限。

信息咨询单独处理：效果前后对比、安全性、剂量、用法、功效、作用机制及明确问句等，未明确口服最高49分，明确口服或补充剂表达最高64分；统一建议“仅供内容研究”，不因补齐商品证据或交易意图进入选品优先池。中文、英文、西语和越南语相关表达按同一规则识别；购买问句（如where/how to buy）本身不当作内容咨询，明确安全或用法语义仍优先。

成分匹配不直接贴“商品需求词”：成分主词为“成分研究词”，只有明确产品/购买表达且不是信息咨询时才标“商品需求词”。成分主词仍可作为研究入口，不因缺剂型或来源意图1一律低分。头发/皮肤等用途词或粉末/液体形态若未明确口服，最高64分并建议“先核验用途”；这些表达本身不证明外用，明确涂抹、护肤、注射等表达才排除。即便存在关联口服商品，也不把上述通用用途词的全部搜索量认定为口服购买需求。

信息咨询与非目标用途先按语义分流；其余缺数据的词显示“先补证据”，用途不明的用途长尾显示“先核验用途”，偏题词显示“排除当前方向”。这些建议优先于单看ABCD评级。人工入选、排除、备注不被自动评分改写。

## 评分输入

| 维度 | 权重 | 来源与边界 |
| --- | --- | --- |
| 成分与研究主题 | 30% | 识别词本身，再与任务主题或种子核对；剂型、剂量不加分 |
| 搜索需求规模 | 25% | 同市场、有来源及日期的月搜索量；固定对数刻度，上沿US十万、MX/VN五万 |
| 需求趋势 | 25% | 优先有效Google时序，否则复用Semrush十二点月趋势，不重复计分 |
| 口服商品文本线索 | 15% | 已关联商品的可追溯原文明确口服用途，固定70分；不按商品数量加分 |
| SEO切入难度 | 5% | 100−自然搜索KD；不代替商品竞争度或利润 |

缺失维度不补0，按已覆盖权重归一化，然后应用门槛。覆盖率是参与评分的输入权重，100%也不意味着全部商业证据已收齐。

Google有效趋势需至少8点、跨度56–800天、存在正热度、最新点距今不超过60天，采集日期45天内；独立日序列另需有效日期和至少60点。Semrush需同市场、12个有效相对值且有正热度，指标与趋势采集日期均在90天内。趋势以持续性40%和动量60%评分，尖峰降权；Google比较近30天与此前30天，Semrush比较最近3点与此前3点。后者不提供逐月日期，不推算逐月搜索次数或同比。

商品原文需180天内、有效HTTP(S) URL、来源ID、指纹、引用包含该词、关联商品ID以及明确口服上下文；外用、注射、科研和否定口服的文本不作为口服线索。原文只证明商品文本提及；商品实际市场、标签、销售与功效仍需人工核验。

Semrush意图编码为0商业、1信息、2导航、3交易；商业意图仅作标签，不充当口服产品证据。新鲜同市场的纯信息意图可辅助判断reviews/results等含糊表达；混合商业意图不单独将其判为信息咨询，但不能抵消明确的安全/用法咨询语义。过期或跨市场意图不参与判断。裸成分主词即使意图为1也保留研究入口。

## 完整性与补齐

详情逐项列出成分、搜索量、趋势、商品文本、KD的状态、来源、日期及解释；列表显示研究建议，导出包含缺项。未采集、采集中、失败、未返回有效数据、过期、市场不匹配和真实0不能混同。完成采集任务不保证每词均被来源收录。

对已授权采集可使用现有补齐指标、趋势采集流程；新模型只复用已有数据，不自动增加收费调用。无法保证穷尽全网数据，只能使已配置来源的缺口可见、可追溯并据此限制决策。相同成分的拼写与语义变体不应相加为独立市场规模，GHK-Cu泛搜索也不能直接当作口服购买量。

评分版本变化会让后台读模型重新投影现有记录，不改变原始采集结果、人工决定或队列，不触发来源请求。
