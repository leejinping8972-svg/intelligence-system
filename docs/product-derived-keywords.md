# 商品反推关键词与非趋势指标

新采集且首次写入的真实商品，通过平台商品保存与独立站商品保存入口自动创建 `product_keywords` 后台任务。商品先保存；关键词任务在现有 runner 锁下执行。如果来源字段分析尚未结束，等待对应任务完成；字段分析补充了原文时，为新快照登记任务，旧快照停止且不能覆盖新状态。已有商品重新采集不会自动追加历史付费回填。

商品页勾选历史商品，点击“提取关键词 / 补齐指标”提交，每批1～100件，仅管理员可用。按商品ID、市场和原文指纹生成固定任务ID，重复点击和网络重试复用原任务。完成情况显示在关联关键词列和“监控与任务”。

## 关键词与依据

- 配置的AI模型一次提取最多6个候选词及中文译名，优先具体成分、商品类型与有原文依据的用途。
- 后端要求词和连续引用确实出现在对应商品来源中，过滤品牌、ASIN、包装数量、单独剂型、否定成分和词内子串误配。不接受模型生成的搜索统计。
- 按“市场＋规范化关键词”合并，复用原ID，保留中文名、收藏、人工审核状态、旧关联与已有指标/趋势，双向追加商品关联。新词进入待审核候选列表，不自动入选。
- 商品提词依据带有 `product_text_candidate` 标识、商品名、来源引用和指纹，区别于平台真实搜索词或流量词。关键词详情展示最近40条依据；请求账本保留完整的已验证候选词结果，验证失败时保留最多2500字符的失败预览，不保存完整原始模型响应。

## 非趋势补齐

只查对应市场的 Semrush `phrase_this` 搜索指标：月搜索量估算、KD、CPC、广告竞争度、搜索意图、结果数，以及该报告开放的其他非趋势字段。请求明确排除 `trend` 字段，不调用扩词、Google趋势、社媒趋势或关联商品扩采；已有趋势数据保留。广告和独立站发现仍由现有独立采集入口控制，不因候选词创建而自动扩大范围。

复用30天内同市场普通指标缓存或专用非趋势缓存，保留原指标日期。新非趋势结果写专用缓存，不能使普通趋势补齐误用缺少趋势的缓存。来源未收录保留未知，不写成0；真实返回0则保留。渠道不可用时商品和成功提取的词仍保留，并展示待补齐/部分完成。

## 请求与恢复

模型和指标请求使用现有 `research_requests`，完成后重启复用响应，`started` 或失败请求不会自动重放。不含失败/未知请求且仍有未完成步骤的任务，手动补做可继续，例如补齐配置后继续尚未发起的指标请求。已存在失败/未知请求时复用历史任务供诊断，不通过新任务ID绕过账本。指标失败写入关键词与商品任务状态，旧成功指标不清空。

无新增依赖、数据库schema/迁移或启动回填。真实运行按用户配置的模型与Semrush规则计费。开发使用合成响应、隔离PGlite和本机浏览器验证；未发起真实收费请求，未集成或正式部署。
